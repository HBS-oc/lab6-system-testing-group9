## About This Repository

This repository is used to report and track bugs found during system testing of the
e-commerce practice site. Each bug is logged as a GitHub Issue using the bug report form
and labeled by **severity**, **priority**, **type**, and **status**.

## Defect Lifecycle

New → Assigned → Fixed → Retest → Verified → Closed
